# پروژه آزمایشگاه هوش مصنوعی — تشخیص دستور صوتی

## تعریف مسئله
هدف طراحی یک عامل هوشمند است که سیگنال صوتی کاربر را دریافت کرده و دستور موجود در آن را در یکی از کلاس‌های از پیش تعیین‌شده (مانند: up, down, left, right, stop, go) تشخیص دهد.

## مؤلفه‌های PEAS

| مؤلفه | توضیح |
|---|---|
| Performance Measure (معیار عملکرد) | دقت تشخیص (Accuracy)، نرخ خطای طبقه‌بندی، سرعت پاسخ‌دهی، پایداری در برابر نویز |
| Environment (محیط) | سیگنال صوتی ورودی (فایل صوتی یا جریان میکروفون) همراه با نویز پس‌زمینه |
| Actuators (عملگرها) | نمایش دستور تشخیص‌داده‌شده و اجرای فرمان متناظر |
| Sensors (حسگرها) | میکروفون یا خواندن فایل صوتی به‌عنوان ورودی |

## مشخصات محیط پروژه (۶ ویژگی)

| ویژگی | وضعیت | توضیح |
|---|---|---|
| قابل مشاهده بودن | جزئی (Partially Observable) | به دلیل وجود نویز، همه اطلاعات سیگنال در دسترس نیست |
| قطعیت | غیرقطعی (Stochastic) | نویز و تنوع گویش باعث غیرقطعی بودن نتیجه می‌شود |
| اپیزودیک / متوالی | اپیزودیک (Episodic) | هر دستور صوتی یک اپیزود مستقل است |
| ایستا / پویا | ایستا (Static) | سیگنال در حین پردازش تغییری نمی‌کند |
| گسسته / پیوسته | پیوسته (Continuous) | سیگنال صوتی پیوسته است |
| تک‌عامله / چندعامله | تک‌عامله (Single-agent) | تنها یک عامل درگیر است |
